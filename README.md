# Competitive Programming

A collection of my competitive programming solutions from DMOJ and various programming contests, including **CCC, CCO, COCI, IOI, USACO, DMOPC**, and others.

## Profile

- **DMOJ:** [daniel_wang123](https://dmoj.ca/user/daniel_wang123)

## Solutions

Solutions are organized by contest under the [`solutions/`](solutions/) directory.

Each filename corresponds to its **DMOJ problem code**. For example:

```text
solutions/CCC/ccc19s2.cpp
```

corresponds to:

https://dmoj.ca/problem/ccc19s2

A complete index of the solutions in this repository can be found in **[SOLUTIONS.md](SOLUTIONS.md)**.

## Languages

Solutions are primarily written in:

- C++
- Python
- Java
